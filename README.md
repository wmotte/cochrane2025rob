# cochrane2025rob

Risk-of-bias data pipeline for Cochrane intervention reviews.

This repository contains scripts and intermediate outputs used to collect Cochrane intervention review metadata, download available review data files, extract study-level and estimate-level risk-of-bias information, scrape reported primary and secondary outcomes, and prepare data for downstream risk-of-bias meta-regression.

The project is organized as a numbered R workflow. Some steps depend on live Cochrane Library pages, while later steps operate on checked-in or locally unpacked review data files.

## Data Sources

The main source is a Cochrane Library CSV export of intervention reviews:

- `00__cochrane_search/citation-export.csv`
- downloaded on 5 June 2025
- Cochrane Library issue 6 of 12, June 2025
- exported from the Cochrane reviews page with review type set to `Intervention`
- abstract excluded from the export

See `00__cochrane_search/readme.md` for the original manual export notes.

Additional data are downloaded or processed into these folders:

- `out.03.rm5s/`: gzipped RevMan 5 `.rm5` data files.
- `out.03.zips/`: Cochrane downloaded ZIP data files and processed CSV summaries.
- `out.04.rob.scraper/`: risk-of-bias tables scraped from Cochrane HTML reference pages.
- `out.05.outcomes.scraper/`: primary and secondary outcome text scraped from review HTML.
- `llm/processing_data/`: intermediate outcome-labeling files generated by the LLM-assisted workflow.

## Repository Layout

```text
.
|-- 00__cochrane_search/          # Cochrane Library CSV export and source notes
|-- 01__cochrane_most_recent.R    # Keep the most recent publication for each review ID
|-- 02__cochrane_check_data.R     # Scrape review pages for downloadable data URLs
|-- 03__cochrane_download.R       # Download review HTML, references HTML, and data files
|-- 04__rob_scraper.R             # Scrape RoB1-like study tables from references HTML
|-- 05__outcomes_scraper.r        # Scrape primary/secondary outcome sections
|-- 06_cluster_ROB.R              # Normalize scraped RoB1 columns into standard domains
|-- 07_process_ROB2.R             # Extract RoB1/RoB2 data from unpacked ZIP exports
|-- 07_primary_vs_secondary.R     # Combine LLM-labeled outcome files
|-- 08_proccess_estimates.R       # Extract estimate/study-level data from RM5 and ZIP data
|-- 08_select_child_health.R      # Select child-health intervention reviews
|-- 99_merge_sources.R            # Load merged RoB sources for downstream analysis
|-- llm/                          # LLM-assisted primary/secondary outcome labeling
|-- misc/                         # Additional raw inputs
`-- out.*                         # Pipeline outputs and intermediate files
```

## Requirements

The scripts are written for R and use CRAN packages directly. There is currently no `renv.lock`, so package versions are not pinned.

Install the R dependencies with:

```r
install.packages(c(
  "dplyr",
  "httr",
  "jsonlite",
  "meta",
  "plyr",
  "purrr",
  "readr",
  "rlang",
  "rvest",
  "stringr",
  "tibble",
  "tidyverse",
  "xml2"
))
```

The LLM outcome-labeling workflow additionally uses Python:

- `llm/llm_labeler.py`: local Ollama model, default `gemma3n`.
- `llm/llm_labeler_gemini.py`: Google Gemini API, default `gemini-2.5-flash-lite-preview-06-17`.

For the Gemini route:

```bash
pip install google-generativeai
export GEMINI_API_KEY="your_api_key_here"
```

For the local Ollama route:

```bash
ollama run gemma3n
```

## Pipeline

Run scripts from the repository root unless otherwise noted.

### 1. Select the Most Recent Review Version

```bash
Rscript 01__cochrane_most_recent.R
```

Input:

- `00__cochrane_search/citation-export.csv`

Output:

- `out.01.cochrane.most.recent/reviews.tsv`

This step removes duplicate review base IDs by keeping the highest publication version, then drops unused citation fields.

### 2. Find Reviews with Downloadable Data

```bash
Rscript 02__cochrane_check_data.R
```

Input:

- `out.01.cochrane.most.recent/reviews.tsv`

Outputs:

- `out.02.cochrane.check.data/reviews_with_rm5_url.tsv`
- `out.02.cochrane.check.data/results_chunk_*.rds`

This step builds Cochrane Library review URLs from DOI values and scrapes pages for `Download data` links. It processes reviews in chunks of 250 and sleeps between requests.

### 3. Download Review Pages and Data Files

```bash
Rscript 03__cochrane_download.R
```

Input:

- `out.02.cochrane.check.data/reviews_with_rm5_url.tsv`

Output:

- `out.03.cochrane.downloads/`

This step downloads:

- main review HTML
- references HTML for `.rm5` downloads
- available review data files, usually `.rm5` or `.zip`

`out.03.cochrane.downloads/` is ignored by Git. The checked-in repository also contains separated historical data folders, notably `out.03.rm5s/` and `out.03.zips/`.

### 4. Scrape Risk-of-Bias Tables from HTML

```bash
Rscript 04__rob_scraper.R
```

Input:

- `out.03.cochrane.downloads/*_references.html`

Output:

- `out.04.rob.scraper/scraped_rob.tsv`

This scraper extracts study characteristics and risk-of-bias judgments from Cochrane reference-page HTML tables.

### 5. Scrape Primary and Secondary Outcome Text

```bash
Rscript 05__outcomes_scraper.r
```

Input:

- `out.03.cochrane.downloads/*_main.html`

Output:

- `out.05.outcomes.scraper/scraped_outcomes.tsv`

This step extracts the review-level `Types of outcome measures` section, with separate columns for primary and secondary outcome text where available.

### 6. Normalize Scraped RoB1 Domains

```bash
Rscript 06_cluster_ROB.R
```

Input:

- `out.04.rob.scraper/scraped_rob.tsv`

Outputs:

- `out.04.rob.scraper/scraped_rob_long.csv`
- `out.04.rob.scraper/scraped_rob_long_processed.csv`
- `out.04.rob.scraper/scraped_rob_wide_processed.csv`

This step maps heterogeneous extracted risk-of-bias column names onto standard RoB1-style domains:

- random sequence generation
- allocation concealment
- blinding of participants and personnel
- blinding of outcome assessment
- combined participant/personnel/outcome blinding field
- incomplete outcome data
- selective outcome reporting
- other bias

Where multiple ratings map to the same domain for a study, the script keeps the worst judgment in the order `High risk`, `Unclear risk`, `Low risk`.

### 7. Extract RoB1 and RoB2 from ZIP Data

Before running this step, unpack ZIP exports into:

```text
out.03.zips/unpacked/
```

Then run:

```bash
Rscript 07_process_ROB2.R
```

Inputs:

- `out.03.zips/unpacked/*-analysis-data/`
- `out.03.zips/unpacked/*-study-data/`

Outputs:

- `out.03.zips/RoB2.csv`
- `out.03.zips/RoB2b.csv`
- `out.03.zips/scraped_rob_long_processed.csv`
- `out.03.zips/scraped_rob_wide_processed.csv`

This step handles both study-level RoB1-like exports and RoB2 data embedded in Cochrane ZIP downloads. RoB2 data are split into estimate-level and study-level variants depending on where they appear in the export.

### 8. Extract Estimate-Level Data

Before running this step, unpack RM5 and ZIP data into:

```text
out.03.rm5s/unpacked/
out.03.zips/unpacked/
```

Then run:

```bash
Rscript 08_proccess_estimates.R
```

Outputs:

- `out.03.rm5s/rm5_data.csv.gz`
- `out.03.zips/zip_data.csv.gz`

This step extracts analysis rows and study-level estimate data from both RM5 and ZIP sources.

### 9. LLM-Assisted Primary/Secondary Outcome Labeling

The LLM workflow lives in `llm/` and should be run from that directory:

```bash
cd llm
Rscript 00__label_outcomes.R
```

Inputs:

- `../out.05.outcomes.scraper/scraped_outcomes.tsv`
- `../out.03.rm5s/*_data.rm5.gz`

Outputs:

- `llm/processing_data/*.json`
- `llm/processing_data/*_labeled.json`
- `llm/processing_data/*_main.tsv`
- `llm/processing_data/*_meta.tsv`

The R script prepares per-review JSON files containing review-reported primary/secondary outcome text and RM5 outcome labels, calls `llm_labeler_gemini.py` by default, then merges LLM labels back into meta-analysis rows.

To combine labeled outputs:

```bash
Rscript 07_primary_vs_secondary.R
```

Output:

- `out.06.primary.vs.secondary/primary_vs_secondary_outcomes.csv`

Note that the combine script currently expects files under `out.06.primary.vs.secondary/processing_data/`, while the LLM script writes to `llm/processing_data/` when run from `llm/`. Move or symlink files accordingly, or adjust the paths before rerunning.

### 10. Child-Health Subset

```bash
Rscript 08_select_child_health.R
```

Input:

- `misc/raw--child-health.csv.gz`

Output:

- `out.08.select.child.health/child_health_intervention_reviews.tsv`

This step selects child-health intervention reviews and flags records whose title or keywords mention adults.

### 11. Load Merged RoB Sources

```bash
Rscript 99_merge_sources.R
```

This script loads the four main processed risk-of-bias sources:

- HTML-scraped study-level RoB1: `out.04.rob.scraper/scraped_rob_wide_processed.csv`
- ZIP-derived study-level RoB1: `out.03.zips/scraped_rob_wide_processed.csv`
- ZIP-derived study-level RoB2: `out.03.zips/RoB2b.csv`
- ZIP-derived estimate-level RoB2: `out.03.zips/RoB2.csv`

It is a starting point for downstream merging and analysis rather than a complete final analysis script.

- `out.06.primary.vs.secondary/processing_data/` is ignored.

## Reproducibility Notes and Caveats

- Live scraping steps depend on the current Cochrane Library HTML structure and may need maintenance if the website changes.
- Downloading and scraping thousands of reviews is slow and should be done politely; the scripts include short sleeps between requests.
- Output directory names are not fully harmonized across historical scripts. Some scripts expect `out.03.cochrane.downloads/`, while checked-in data are also organized into `out.03.rm5s/` and `out.03.zips/`.
- ZIP and RM5 processing assumes data have already been unpacked into ignored `unpacked/` directories.
- The LLM labeling workflow is experimental and depends on either a local Ollama model or an external Gemini API key.
- There is no package lockfile, so exact numerical reproducibility may depend on local R and package versions.
- Cochrane review data may be subject to Cochrane Library terms of use. Check source licensing and access requirements before redistributing downloaded data.
